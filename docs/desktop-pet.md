# 迷途之子 · 像素桌宠

## 启动

在项目目录运行 `npm run desktop`。它启动本地网页服务与 Electron 桌宠。开发窗口目前运行在 Mac；Windows 尚未验证，也还没有制作安装包。

网页预览为启动日志中的地址加 `?mode=pet-preview`。原有对话页右上角新增“桌宠”入口。在 Electron 对话窗口内会显示原生桌宠，在普通浏览器中则打开预览页。

## 互动

- 点击角色：摸头；按住拖动：移动位置。
- 角色脚下的背包按钮：展开或收起互动面板。
- 月亮按钮：休息或叫醒；休息时不能投喂。
- 背包：投喂小饼干、抹茶蛋糕、饭团；加号用星星购买一份。
- 同行：切换五位角色；各自拥有独立亲密度、饱腹和心情。
- 奖励：签到、摸头三次、投喂一次、实际散步二十秒，完成后领取星星，同一天不可重复领取。
- 自由散步：收起面板后在当前位置附近短途走动；每走完一段会停留约 6.5～14 秒，不再反复横穿屏幕。打开面板、拖拽、休息和编程陪伴时暂停散步。
- 步速：悠闲／自然／活泼三档，分别约为 28／40／54 像素每秒的巡航上限；起步和停步会放缓，两幅步行图跟随真实行走距离交替，而非独立计时播放。
- 大小：小／中／大；房屋按钮返回对话窗口。

库存、亲密度、星星、位置、散步开关和步速保存在本机。普通浏览器与 Electron 的存储空间独立，目前不在两者之间同步。

动作节奏参考了 [Shimeji-ee](https://github.com/DalekCraft2/Shimeji-Desktop) 的可配置行为、[oneko-swift](https://github.com/oneko-swift/oneko-swift) 的速度档，以及 [desktopPet](https://github.com/kokoronoka/desktopPet) 的随机散步间隔；只借鉴交互原则，没有复制这些项目的代码或素材。刻意没有照搬追逐光标、抢输入等打断工作的行为。

## 专注零食

仅原生桌面版检测前台应用的 bundle ID。不会读取窗口标题、屏幕、文档或按键内容，无需辅助功能权限。网页预览不能检测其他软件，学习按钮在那里禁用。

- VS Code、Cursor、Xcode、JetBrains 系列、Zed、Sublime 等前台代码软件自动计时；连续 120 秒没有系统输入时暂停。这是应用级启发式识别，不证明真的在写代码。
- 检测为「编程中」时，桌宠会停止自由散步，切换为一套双帧编程陪伴动作：爱音／乐奈拨吉他，灯看笔记，素世弹贝斯，立希敲鼓点。切出代码软件后恢复原有动作；摸头、投喂、拖拽、休息仍优先。浏览器可用 `?mode=pet-preview&demo=coding` 只预览姿势，既不检测代码软件，也不累计专注时间。
- 视频学习采用用户选择的手动“学习模式”；只有 Chrome、Safari、Firefox、Edge、Arc、哔哩哔哩、QuickTime、IINA 或 VLC 在前台时计时。不会读取视频内容，也不会自动区分娱乐和学习。
- 学习中允许长时间不动鼠标，以免打断观看；锁屏、系统休眠、切到非代码／非学习应用、暂停开关或识别失败均停止计时。
- 每累计 300 秒获得一份食物，依次循环小饼干、抹茶蛋糕、饭团。小于五分钟的进度保留，奖励自动进背包，每种库存最多 99；已满的那份不会暂存补发。
- 手动学习模式每次启动默认关闭，防止无意继续挂机；专注暂停开关和获得的库存、累计进度保留。退出桌宠期间不计时。

主进程保存有效累计秒数到其应用数据目录的 `mitu-focus-progress.json`，不保存前台应用历史。渲染界面按累计秒数差值发奖，重复轮询和刷新不会重复发放；第一次连接先建立基线，不补发旧计时器历史。

## 安全与边界

渲染页面不能访问 Node；只暴露显示／隐藏桌宠、打开对话及交互区域等有限操作。服务仅监听本机。原生窗口按角色与面板的区域决定是否接收鼠标，空白区域设计为穿透；此行为及桌面拖动仍需真实鼠标验证。

首版只在主显示器工作区域活动，不跨屏移动。不含语音、YOLO、真实 LLM 对话或系统自动操作。像素图由用户确认的生成素材构成，不是 Live2D。

现有依赖审计报告 6 项高等级问题，来自原 Live2D 库的 `gh-pages → globby → fast-glob → micromatch → braces` 依赖链；本轮没有扩大修改该渲染栈，也未执行自动升级。制作正式安装包前需处理依赖审计。

- Electron 窗口显示成功；透明捕获中能看到角色及快捷按钮，原生鼠标穿透与拖动仍需真人鼠标验收。
