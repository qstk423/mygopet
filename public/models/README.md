# Local Live2D resources

The MyGO!!!!! model collection and its Cubism 2 runtime are kept locally in the ignored `work/mygo-reference/` directory. The development server reads five members and 74 outfit models from that collection; it does not copy those character assets or the runtime into `public/` or production build output.

The upstream repository identifies the model assets as game data, for learning/communication only, and says not to use them commercially. Open-source code licensing does not grant rights to redistribute the character models or runtime. Check the upstream terms and rights-holder requirements before publishing or submitting a build that contains these assets.

If this workspace is moved to another computer, re-download the upstream project locally before starting the development server. The website source and build remain separate from the model resources.
